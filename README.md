# enigma-engine
enigma-engine is a collection of tools and utilities to make it even easier to make games with enigma. enigma-engine runs on enigma itself.

clone the repo and run `cargo run` in it. 
This is a weekend vibed project so it might have quite some bugs, but it already showcases the engines capabilities.

To access enigma-3d source code, look at: https://github.com/JeremiasMeister/enigma-3d
