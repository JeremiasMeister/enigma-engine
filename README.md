# enigma-engine
enigma-engine is a collection of tools and utilities to make it even easier to make games with enigma. enigma-engine runs on enigma itself.


## Visual UI editor

Build menus, HUDs and data-driven RPG dialogue in the **UI** workspace, with custom textures, sprite regions and reusable styles. See the [UI editor guide](docs/ui-editor.md) for authoring and generated Rust integration.

## Development Roadmap

See the [game development roadmap](docs/game-development-roadmap.md) for priorities, the current session checkpoint, and the working agreement. Editor changes may be assistant-implemented; `enigma-3d` changes are guided learning work that the owner types manually. Development proceeds incrementally in free time.
