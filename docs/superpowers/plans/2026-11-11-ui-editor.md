# Visual UI Editor Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the approved UI workspace with Rust export and procedural RPG dialogue.

**Architecture:** A serializable UI document and shared egui renderer are compiled into the editor and copied into generated game modules. The editor owns authoring/history; generated classes own transient data and emit events after releasing their AppState borrow.

**Tech Stack:** Rust 2021, egui 0.23, serde/serde_json, existing enigma-3d APIs.

**Spec:** ../specs/2026-11-11-ui-editor-design.md

## Global Constraints

- Only modify enigma-engine; preserve AGENTS.md and machine-specific dependency patches.
- Add only the cached image decoder dependency to the editor; generated games need no new dependencies. Existing project files deserialize with empty UI screens.
- Generated files cannot overwrite user-authored files. Export validates the entire set before writing.
- Preview uses cloned data. Stable row IDs travel with events.

## Review Focus

- Invalid graph/geometry or names must fail validation before export.
- Empty or reordered choice lists must not reuse another row's state or event identity.
- Switching screens/projects must not leak selection, history, or preview state.
- Failed export/save must retain dirty work and show an actionable error.
- Text-input shortcuts and UI dragging must never reach scene operations.
